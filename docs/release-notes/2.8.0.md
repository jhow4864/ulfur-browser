**Engine**
* **GeckoView 158.** Ulfur moves to Mozilla's GeckoView 158, the same engine as Firefox 158, with its security fixes.

**New features**
* **Alternate app icons.** Settings › Appearance › App icon lets you pick the Default howling-moon icon or one of
  eight colourways that match the themes: Blood Moon, Frost, Toxic, Ember, Void, Gold, Sakura and Ash. Some launchers
  take a moment to show the new icon.
* **Add to Home screen.** Menu › Add to Home screen pins a shortcut that opens the current page in Ulfur. The icon is
  a letter tile in your accent colour, because Ulfur doesn't fetch site icons outside its privacy protections. The
  option is hidden in private and Ghost tabs so private pages never reach your home screen.

**Changes**
* **Ulfur Monitor replaces Ulfur Control.** It still shows live CPU, memory and network use. The three "limit"
  sliders are gone because they never limited anything; they only changed the colour of the figures.
* **Video download button in the address bar, on by default.** When a page has a video Ulfur can save, a download
  button shows in the address bar; tap it to save. You can turn it off in Settings › General › Video download button.
* **Media Radar is gone.** The full-screen radar overlay, its menu entry and the long-press on the download button have
  been removed. The download button and save sheet do the same job.
* **arm64 only.** Ulfur is built for 64-bit ARM phones only, and the README now says so. There's no 32-bit build.
